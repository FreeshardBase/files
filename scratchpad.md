## Key Architectural Decisions & Patterns
- Dropbox Webhooks & Delta Sync (`server/providers/dropbox.js`, `server/routes/providers.js`): Public GET/POST routes `/api/providers/dropbox/webhook` registered before `requireAuth` middleware to allow unauthenticated Dropbox callbacks. GET returns plain text `challenge` for webhook verification; POST verifies `X-Dropbox-Signature` header via HMAC-SHA256 with `DROPBOX_CLIENT_SECRET`. `DropboxProvider` exposes `getLatestCursor`, `listFolderContinue`, and `fetchDelta` for paginated delta change consumption.
- User Search & Autocomplete for Internal Sharing (`server/db.js`, `server/routes/sharing.js`, `public/index.html`, `public/js/filebrowser.js`): `searchUsers(query, currentUserId, limit)` performs SQL wildcard matching across `username`, `display_name`, and `email` columns, excluding the authenticated user and default-user. Exposed via `GET /api/shares/users/search?q=query` and wired to HTML5 `#userAutocompleteList` datalist with live input debouncing in internal share modal.
- OIDC Profile Photo Integration (`server/db.js`, `server/routes/auth.js`, `public/js/app.js`): Extracts `picture` / `avatar_url` claim during OIDC token callback, stores URL in `users.avatar_url` column via `upsertUser`, exposes `avatarUrl` property on `GET /api/auth/me`, and dynamically renders circular profile avatar image in header bar.
- PWA & Offline Caching Engine (`public/manifest.json`, `public/sw.js`, `public/index.html`): `manifest.json` defines standalone web app configuration; `sw.js` handles `install`, `activate`, and `fetch` events with static asset caching (`freeshard-files-v1`) and HTML request fallback for offline operation. Registered via `navigator.serviceWorker.register('/sw.js')` in `index.html`.
- Smart Folders & Saved Dynamic Search Views (`server/db.js`, `server/routes/files.js`, `server/utils/smart_folders.js`): Stores search criteria (query and JSON filter spec) in `smart_folders` table. `evaluateSmartFolder(userRoot, smartFolder)` recursively walks the user root directory evaluating text queries, extension arrays, category mappings (`documents`, `images`, `videos`, `audio`, `archives`, `code`), file size ranges, and modification date ranges, returning dynamic virtual folder items.
- Role-Based Access Control & Audit Log Engine (`server/db.js`, `server/routes/admin.js`, `server/routes/activity.js`): User roles (`admin`, `user`, `viewer`, `editor`) stored on `users` table; `admin_audit_log` tracks administrative actions (e.g. `role_change`) with admin ID, target user ID, and IP address; `file_access_logs` logs role-based access events (`granted`/`denied`).
- Chunked Resumable Upload Protocol (TUS.io) (`server/routes/transfers.js`): In-memory session tracking (`tusSessions`) for offset state and chunk concatenation into user home temporary files (`.tmp/tus_*.tmp`). Supports `Upload-Metadata` base64 key-value decoding (`filename`, `destinationPath`), offset mismatch conflict detection (`HTTP 409`), and automatic file relocation upon reaching `Upload-Length`.
- Webhooks & Personal Access Token (PAT) Engine (`server/db.js`, `server/middleware/auth.js`, `server/routes/webhooks.js`): Generates cryptographically secure API tokens (`fs_pat_...`) stored in `personal_access_tokens` table. `requireAuth` middleware intercepts `Authorization: Bearer` or `X-PAT-Token` headers to authenticate API calls without active session cookies, tracking token last-used timestamp (`last_used_at`) and enforcing expiration rules (`expires_at`).
- Client-Side PDF Tools Engine (`server/utils/pdf_tools.js`, `server/routes/files.js`, `public/js/filebrowser.js`): Pure buffer-level PDF parser/manipulator supporting page rotation (`/Rotate` dict manipulation), multi-range page splitting, and object re-indexing multi-document merging exposed via `/api/files/pdf/*` REST API.
- Event-Driven Rule Automation Engine (`server/utils/webhook_dispatcher.js`, `server/db.js`, `server/routes/webhooks.js`): Evaluates file event triggers (`file_created`, etc.) against user-defined rule patterns (`file_automation_rules`). Automatically executes physical file relocation (`move`), database tagging (`tag`), or custom processing (`process`) during event dispatch.
- Centralized Settings Engine (`server/routes/auth.js`, `public/index.html`, `public/js/filebrowser.js`): Consolidates profile preferences (display name, language, click mode, theme tokens) with API / WebDAV app password token management in `#modalSettings`.
- Cross-Shard Federated Sharing Engine (`server/routes/sharing.js`, `server/db.js`): Manages outbound and inbound federated file shares across peer shards. Stores tokenized access records in `federated_shares` and `inbound_federated_shares`, automatically cascading path updates on folder moves (`updateSharePathsOnMove`) and supporting user handle resolution (`user@target_shard`).
- Storage Analytics Engine (`server/utils/storage_analytics.js`): Recursively inspects user root storage, mapping extensions to standard file categories (`CATEGORY_MAP`) and combining local directory usage with registered provider quotas (`provider_connections`). Exposes `GET /api/storage/analytics`.
- Keyboard Navigation Engine (`public/js/filebrowser.js`): `handleKeyDown(e)` intercepts keyboard events when non-input elements are active. Manages item selection indices, multi-selection state, and internal clipboard (`this.internalClipboard`) for copy/paste operations without polluting browser system clipboard.
- Favorites / Quick Access (`favorites` table) maintains user-pinned file/folder paths with cascade updates on file move (`updateFavoritePathsOnMove`) and auto-removal on delete (`removeFavorite`).
- `searchUniversal(userId, query)` queries full-text file search (`files_fts`), public & internal file shares (`public_shares`, `file_shares`), user file tags (`file_tags`), and ecosystem ingest records (`ecosystem_ingest_log`).
- `GET /api/search/universal` returns categorized search results and formats cross-app deep links for Paperless, Immich, public shares, and files.
- `legal_holds` SQLite table tracks file retention policies, lock expiration dates, reasons, and active/released statuses.
- `checkActiveLegalHold(userId, path)` intercepts deletion (soft/trash/permanent) and file overwrites in `files.js` and `trash.js` returning HTTP 403 when active hold is present.
- `file_requests` SQLite table stores token, owner `user_id`, `target_folder`, expiration, and upload caps (`max_uploads`, `upload_count`).
- High-Availability `FailoverProvider` wraps primary and secondary storage nodes, automatically detecting I/O errors and falling back to replica storage while providing `GET /api/storage/health` telemetry.
- Architectural Security Guardrails: `safepath.js` handles URI multi-pass decoding and symlink checks; `isolation.js` provisions user home roots and enforces quota/path limits; `crypto.js` enforces AES-256-GCM with 32-byte `ENCRYPTION_KEY`.
